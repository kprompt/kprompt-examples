# kprompt-examples Autonomous Ship Loop

This module implements an autonomous ship loop to keep `kprompt/kprompt-examples` shipping real capabilities under a monthly spend cap with survivor selection.

## Features

- **Monthly spend cap enforcement:** Prevents shipping features that would exceed the monthly budget.
- **Survivor selection:** Allows custom survivor selection strategies to pick which features to ship.
- **State management:** Tracks spend and shipped features per month.
- **Reset capability:** Resets state for a new month.
